StyleOS is an advanced console shell environment for Windows developed in C# that bridges the gap between retro terminal aesthetics and modern system functionality. The project focuses on providing a high-detail UI/UX within a command-line interface, including support for graphics and system automation.

## Key Features
* **Graphic Engine:** Implements a unique image rendering system using half-block characters to achieve higher vertical resolution in the console.
* **Intelligent Boot Sequence:** Features a fullscreen startup sequence with specialized loading animations and custom splash screen support.
* **Debug Mode:** Accessible via F6 at startup, this mode provides deep monitoring of system calls and kernel module loading.
* **Update System (Pacman):** An integrated manager that synchronizes with GitHub Releases to handle system updates.
* **Security:** Includes a built-in authentication system supporting Root privileges and SHA-256 password encryption.
* **Integrated Tools:** Includes the Nano text editor, a package manager, network utilities (ping, wget, curl), and a dedicated bug reporting system.

## Installation
1. Download the latest release from the Releases section.
2. Extract the archive and execute `StyleOS.exe`.
3. Create a Root account during the initial setup.

## Shortcuts
* **F6 (During Boot):** Enter the System Recovery and Debug Menu.
* **Ctrl + S (In BugReport):** Send the report and system logs to the developer.
* **Ctrl + S (In Nano):** Save the current file.
